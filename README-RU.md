## 🔥 Избранные проекты

### 🛡️ **Sheriff - Система управления объектами**
Комплексная система контроля объектов с мониторингом в реальном времени и управлением безопасностью
- **Технологии:** React, Node.js, Express, MongoDB, WebSocket
- **Особенности:** Мониторинг в реальном времени, управление безопасностью, аналитическая панель
- 🔗 [Демо](https://sheriff.amirsalmani.com/)

### 💰 **Платформа торговли криптовалютами** 
Торговая платформа с данными рынка в реальном времени и обработкой транзакций
- **Технологии:** React, Redux, Node.js, MongoDB, Real-time APIs
- **Особенности:** Анализ рынка, управление портфолио, безопасные транзакции
- 🔗 Торговая система

### 🏢 **Alalam Jamel - Платформа бизнес-услуг**
Платформа создания бизнеса для рынка Дубая с консультационными услугами
- **Технологии:** Next.js, Figma, TailwindCSS, API интеграция
- **Особенности:** Регистрация бизнеса, бронирование консультаций, управление документами
- 🔗 [Посмотреть проект](https://alalamjamel.com/)

### 🎵 **Nilram Music Gallery**
Музыкальная платформа с 3D визуализацией и пользовательскими аудио функциями
- **Технологии:** React, Three.js, Node.js, API обработки аудио
- **Особенности:** 3D визуализация музыки, пользовательские аудио сообщения, интерактивная галерея
- 🔗 [Попробовать](https://nilramgallery.ir/)
